# snowball community health files

Default [CONTRIBUTING.md](CONTRIBUTING.md) and [SECURITY.md](SECURITY.md) for
every repository in the snowball-projects organization. GitHub applies these to
any repository that does not provide its own.

A repository with rules specific to its data, interfaces or checks keeps its
own `CONTRIBUTING.md`, which takes precedence.

The security policy does not enable private vulnerability reporting. Maintainers
should check whether **Security → Report a vulnerability** is available in each
repository and consider enabling it. If it is unavailable, the policy permits
only a public request for a private channel, with no vulnerability details.
