snowball is an open-source software lab making free apps.

[Principles](https://snowball-projects.github.io/principles/)

- sideline: [fantasy football injury comparator](https://snowball-projects.github.io/sideline/)
- kickoff: [sports event calendar](https://snowball-projects.github.io/kickoff/)
- fairway: [open golf course data and map](https://snowball-projects.github.io/fairway/)

## License

Code is MIT. Data we create is CC0, free to use for anything. Data from others keeps its source's license and credit; for example, fairway's course data comes from OpenStreetMap under ODbL.

Bug reports and ideas are welcome as issues in each project's repo.
